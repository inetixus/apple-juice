## 1. Add Schema Markup (Medium Priority)

The lack of Schema.org structured data is the biggest remaining blocker on your On-Page/GEO checklist. Because Apple Juice is an open-source development tool, a `SoftwareApplication` schema is perfect.

Paste this exact script anywhere inside your `<head>` tags:

```html
<script type="application/ld+json">
{
  "@context": "https://schema.org",
  "@type": "SoftwareApplication",
  "name": "Apple Juice",
  "operatingSystem": "Windows, macOS, Linux",
  "applicationCategory": "DeveloperApplication",
  "applicationSubCategory": "AI Code Editor / Roblox Studio Plugin",
  "offers": {
    "@type": "Offer",
    "price": "0.00",
    "priceCurrency": "USD"
  },
  "description": "An open-source AI code tool and CLI agent for Roblox Studio that automates Luau scripting and game development.",
  "softwareVersion": "1.0",
  "license": "https://github.com/your-repo-path/blob/main/LICENSE"
}
</script>

```

## 3. Fix the Mobile PageSpeed & JS Bottlenecks

Your desktop load speed is solid, but your mobile performance is struggling (Largest Contentful Paint is taking 6.3 seconds). The audit highlights two main culprits:

### Fix the JavaScript Load Errors

Your page is loading **11 different JavaScript files**, and some are throwing unhandled runtime errors on boot. This stops the browser from rendering the page efficiently.

* **Action:** Open your site in Chrome or Edge, right-click anywhere, hit **Inspect**, and click the **Console** tab. Look for the red error messages. If you are bundling with Next.js/Tailwind, make sure you aren't accidentally importing heavy desktop libraries or node modules that are failing or running unnecessary scripts on the client side.

### Eliminate Multiple Page Redirects

The audit noted a `0.63s` delay caused by redirects. This usually happens when a user requests `http://apple-juice.online` and gets shuffled around sequentially: `http` $\rightarrow$ `https` $\rightarrow$ `https://www`.

* **Action:** In your Cloudflare dashboard, go to **Rules** -> **Redirect Rules** (or Page Rules) and ensure you have a single rule that instantly catches all traffic and forces it to your primary root domain cleanly in a single step. Make sure the DNS records for both `@` and `www` are actively proxied (the orange cloud icon should be turned on).

## 4. Why is Cloudflare Flagging HTTP/2?

Even though Cloudflare shows `HTTP/3` under your technology list, the audit scanner is complaining about an outdated protocol. This happens if the crawler hits an asset hosted on an external server or a non-proxied subdomain.

* **Action:** Go to your Cloudflare dashboard under **Network**, double-check that **HTTP/2** and **gRPC** are toggled on, and verify that any asset links (like images or external code snippets) are hosted locally on your domain rather than being pulled from a raw un-proxied server.
