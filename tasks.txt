[x] 3. Bridge / MCP endpoint auth audit
    DONE. Findings:
    - /api/mcp/enqueue + /api/mcp/poll (VPS-facing): Bearer AJ_BRIDGE_SECRET +
      valid session + server-side tool allowlist. Solid.
    - /api/mcp/next + /api/mcp/result (plugin-facing): were session-key only.

    >=128 bits for the dashboard path, keep the short human code only for initial
    pairing, then issue a long key. Tracked as task 3b below.

[x] WEBSITE PURCHASES via browser extension (age-gate workaround)
    PROBLEM: the Roblox shop game is rated 16+, so under-16 / non-age-checked
    users can't enter it to buy plans/refills. A real payment processor (Stripe
    etc.) isn't viable (owner is a minor — can't be merchant of record).
    SOLUTION: a Chrome extension that DETECTS (never makes) a purchase the user
    completes through Roblox's own flow, then relays it to the site to unlock.
    Built:
    - extension/ (MV3): inject.js observes the page's own purchase fetch/XHR
      (read-only) + roblox-detect.js DOM observer; relays { productId } to the
      API with credentials. Listener only — no automation, ToS-safe.
    - /api/extension/purchase: grants to the Roblox userId from the AUTHENTICATED
      session (forge-proof — only affects caller's own account), then RE-VERIFIES
      with Roblox before granting (gamepass ownership / Open Cloud active-sub).
      Fails closed. Dev-product refills aren't verifiable post-hoc, so they're
      rejected here and still flow through the authoritative in-game webhook.
    - src/lib/roblox-products.ts: shared product→grant map (webhook + extension
      use one source of truth). Webhook refactored onto it.
    - src/lib/roblox-verify.ts: server-side Roblox ownership/subscription checks.
    - /extension page + landing pricing note + downloadable zip in public/.
    - New env: ROBLOX_WEBHOOK_SECRET (existing), ROBLOX_OPEN_CLOUD_KEY +
      ROBLOX_UNIVERSE_ID (subscription verification). Tests added (90 pass).
    FOLLOW-UP (you): still worth re-checking the game's maturity questionnaire —
    a pure shop game usually rates 9+/13+, which fixes this at the source.
