Floating hero game cards — image drop-in folder
================================================

The landing hero (FloatingGameCards) loads card art from this folder. Drop
images here using these exact filenames and they appear automatically:

  oil.webp
  shooter.webp
  bedwars.webp
  zombie.webp
  pets.webp
  police.webp
  mansion.webp   (available; not in the default 6-card layout)
  pvp.webp       (available; not in the default 6-card layout)

Recommended: ~356x440 (2x of the 168x220 card), .webp, object-cover safe.

Any missing file falls back to a themed gradient card automatically, so the
hero always looks finished.

LICENSING — read before adding images
--------------------------------------
Only add images you have the right to use:
  - screenshots of YOUR OWN demo games
  - art/photos you have licensed
  - media you have explicit permission to use

Do NOT add screenshots of other studios' Roblox games. Those screenshots are
owned by their creators; neither we nor anyone else gains rights to them by
copying them from a third party. Using them exposes the brand to IP claims.
